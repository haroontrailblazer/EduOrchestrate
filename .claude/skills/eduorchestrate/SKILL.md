# EduOrchestrate

Use `/eduorchestrate` as the learner command.

When invoked, ask for missing learner profile details, generate or update the 30-day plan, keep recommendations practical and sourced, and use the NPX CLI for local state:

```bash
npx eduorchestrate
npx eduorchestrate send-today --dry-run
```
